# **App Name**: Budmaps Navigator

## Core Features:

- Category Browsing: Browse dispensaries by category using visually appealing image-based category tiles.
- Featured Dispensaries Showcase: Display a curated selection of featured dispensaries with images and names.
- Region-Based Organization: Organize dispensaries by city regions in a clear, columnar layout for easy navigation.
- Search Bar: Allow users to search dispensaries and products with an intuitive search bar.

## Style Guidelines:

- Primary color: Black (#000000) for backgrounds and text.
- Secondary color: Green (#4CAF50) to highlight interactive elements and key information.
- Body and headline font: 'Inter', a grotesque-style sans-serif font with a modern, machined, objective, neutral look; well-suited for both headlines and body text.  
- Use minimalist icons to represent categories and navigation elements.
- Responsive design adapting to different screen sizes, with a clean, modern, minimalist aesthetic inspired by Weedmaps.
